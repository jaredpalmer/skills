# Changelog Corpus Manifest

Reference prose collected from the public changelogs of **Vercel** (vercel.com/changelog) and **Cursor** (cursor.com/changelog) for writing-style analysis.

- **Vercel entries:** 20 (`vercel/vercel-*.md`)
- **Cursor entries:** 25 (`cursor/cursor-*.md`)
- **Total:** 45 entries, ~6,100 words of prose
- **Date range:** March 2024 – July 2026 (majority 2026)

Each file contains only the human-written prose of one changelog entry: title, date, source URL, and body paragraphs/bullets. Navigation, cookie banners, images, code blocks, and site boilerplate (e.g. Vercel's "📚 More updates" footer) were stripped. Short inline code mentions and documentation links that are part of the prose were kept.

## Collection notes and caveats

- Entries were captured via web-search result excerpts of the live pages (direct fetching was unavailable in the collection environment). Prose is verbatim from the source pages, but a few entries had truncated passages in the excerpts; truncated fragments were **omitted** rather than reconstructed. Known cases:
  - `vercel-001` (AI SDK 7): only the intro paragraphs and one upgrade-path item were fully captured; the detailed migration sections are omitted.
  - `vercel-003` (Routing rules): a mid-entry bullet list was truncated and omitted; all paragraphs are complete.
  - `cursor-001` (3.0): item counts were removed from section headings (e.g. "Editor (4)" → "Editor") and one truncated trailing bullet omitted.
  - `cursor-014` (3.8): the "An emoji trigger for Slack" section body was not captured and the section is omitted.
  - `cursor-016` (3.11): the "Side chats" section body and some picker-improvement bullets were truncated and omitted.
  - `cursor-024` (2.2): the "Debug Mode" section body was not captured and is omitted.
- Minor reconstructions (flagged for transparency):
  - `cursor-020` (2.4): the `### Skills` heading was inferred; the paragraph beneath it is verbatim. The `### Subagents` section body was not captured.
  - `vercel-008`: the publish date (July 17, 2026) comes from third-party corroboration of Vercel's changelog; the excerpt of Vercel's page did not include the date line. All body text is verbatim.
- `cursor-025` is from Cursor's CLI changelog docs page (docs/cli/changelog), which is official Cursor release-note prose with the same voice as the main changelog.
